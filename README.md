## How it works

- Hold continuously for **30 days** → claim **1,000 AXLV**
- Keep holding → claim another **1,000 AXLV** each extra completed month
- Sell to zero → hold streak resets
- Bonuses are paid from the on-contract reward pool (`fundRewardPool`)
- Claims require a funded pool (*subject to reward pool funding*)
